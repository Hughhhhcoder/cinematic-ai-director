# Third-party references and notices

This repository contains original code, schemas, templates, and analysis. External material is linked for evidence and terminology; full third-party prompts, media, model weights, and proprietary code are not redistributed.

## Public technical sources

- [Higgsfield public projects and articles](https://higgsfield.ai/): reference roles, camera-control vocabulary, consistency workflows, prompting behavior, and platform adapter research. Higgsfield is not called by this Skill.
- [OpenAI image-generation documentation](https://developers.openai.com/api/docs/guides/image-generation): model limitations and workflow reproducibility boundary. The Skill uses Codex built-in ImageGen, not the external API.
- [ARRI](https://www.arri.com/), [Sony CineAlta](https://pro.sony/), [Kodak Motion Picture Film](https://www.kodak.com/en/motion/), and [Cooke Optics](https://cookeoptics.com/): observable capture, format, optical, exposure, and medium behavior.
- [PBRT](https://pbr-book.org/): volume-scattering concepts.
- [MediaPipe](https://github.com/google-ai-edge/mediapipe), [SMPL-X](https://github.com/vchoutas/smplx), [VBench](https://github.com/Vchitect/VBench), and [PhyGenBench](https://github.com/OpenGVLab/PhyGenBench): terminology for human topology and manual temporal/physics QA. None is installed or redistributed.
- PhotoMaker, StoryMaker, and StoryDiffusion are research evidence for reference and sequence design. They are not runtime dependencies.
