# 实拍真实性：从现实证据而不是“电影感”出发

本文件回答一个独立于摄影技术的问题：画面是否像真实世界在某个具体条件下被摄影机记录，而不是像模型生成的精致剧照。`photographic_qa` 负责机位、镜头、焦点、曝光和光路能否重建；`authenticity_qa` 负责观众是否仍会立即闻到 AI 味。两者缺一不可。

## 真实性合同

每张真人图在生成前先写清五件事：

1. **现实对象**：这个人、地点或物件为什么不是同类题材的平均值。
2. **因果证据**：年龄、职业、使用、天气、施工、维护和时间如何留下可见结果。
3. **摄影发生条件**：谁在拍、为何能站在这里、设备能否到达、当下有什么操作限制。
4. **合理妥协**：哪些焦点、曝光、遮挡、裁切或白平衡不完美是由现场造成的。
5. **题材契约**：观察式剧情、年代纪实、动作、广告或 MV 分别允许多大程度的设计与精致。

不要主动添加瑕疵来证明真实。没有物理原因的歪斜、脏镜头、彩边、颗粒、雾、雨、逆光和遮挡，与塑料皮肤一样是假。

## Reality Brief

在摄影 thesis 之前，把以下内容写入 `creative-bible.md`：

- **Casting truth**：年龄范围、体型与重量分布、脸部和身体不对称、职业/生活痕迹、姿态习惯；哪些“默认模特化”特征不属于角色。
- **Location truth**：建筑用途、年代、平面关系、施工材料、公共设施、维护水平、人员流线、当地气候和实际光源。
- **Production causality**：每件显眼物品为何存在、谁放置或使用、磨损发生在哪里；禁止为了“丰富”平均铺满道具。
- **Camera witness**：摄影者是观察者、剧情内记录者、受控剧组、安保设备还是商业棚拍；摄影机入口、通路和工作距离。
- **Polish ceiling**：该项目允许的妆发、布光、构图、皮肤修饰、清洁度与后期精度上限。
- **AI priors to reject**：题材最容易触发的模板脸、豪华场景、青橙色、无来源轮廓光、广告式中心构图、装饰雾、假文字等。

## 三类现实锚点

### 人物／选角锚点

人物母版是 casting evidence，不是海报。优先描述骨骼比例、面部宽窄、眼睑和眉形差异、鼻/嘴不对称、皮肤色差、发际线、手部、肩颈与站姿，再描述服装。职业痕迹必须落在合理部位，例如长期户外工作的颈侧与手背、重复劳动造成的姿态、经常携带工具造成的局部磨损。

硬失败包括：默认年轻俊美脸、两侧完全对称、妆容和皮肤像美妆广告、发丝均匀到像渲染、眼白/牙齿发光、每个角色拥有同一种“AI 深邃眼神”。

### 地点／勘景锚点

地点母版像 location scout photo：无人、空间可读、自然透视、普通但可解释的光。真实细节来自建造与使用逻辑：插座和管线连接到哪里，空调外机如何固定，门和地面的磨损对应怎样的流线，水渍从何处开始，货物为何堆在那里。

地点真实性还必须跨视角成立。每个场景状态的建立图和侧面三分之四图共享同一固定主锚点；门窗、设施、材料、交通磨损、光源方向、锚点接地/尺度/朝向能在固定坐标系中互相推导。两个各自真实但无法组成同一空间的房间仍然失败。见 [spatial-system.md](spatial-system.md)。

硬失败包括：随机脏乱、每面墙都“有故事”、灯具无电源、家具尺度冲突、所有表面拥有同一种磨损、为了电影感而出现的雾、雨、霓虹或光柱。

### 物件锚点

物件参考记录制造结构、尺寸、材料、连接方式、受力点、握持区和剧情状态。关键道具需用多角度参考，但每个输出仍是一项资产。磨损沿真实接触和运动发生，不在整件物体上均匀喷旧。

## Capture Circumstance

叙事画面和 Look Test 的 Profile 必须包含：

- `observer_role`：谁或什么系统在记录。
- `camera_access`：摄影机从何处进入，离主体和障碍大致多远。
- `operator_constraint`：空间、时间、身体、设备或表演对操作造成的限制。
- `allowed_contingency`：由该限制合理产生的局部遮挡、边缘裁切、曝光或焦点妥协；没有则明确写 none。
- `off_frame_context`：画外仍真实存在并影响画内的墙体、光源、人物或行动。

观察式画面可以有不完整的视觉信息；精密广告可以高度受控。真实性不是统一粗糙，而是拍摄方式符合 brief。

## 皮肤不是“高光材质”，而是受光证据

出现人物时，把皮肤照明当作可重建光路，而不是美化风格：

1. 指认主光究竟是窗、天空、太阳、灯具、火光、显示屏还是反射面，并记录其相对尺寸与方向。
2. 先判断人物是干燥、局部出汗、雨湿、水湿还是剧情特定油污，再决定高光能覆盖哪里。没有状态依据时默认 `dry`。
3. 大光源应产生宽而弱的连续高光与较软阴影；小而近的硬光才会产生小亮点和硬边。高光不能独立于光源复制到所有面部凸起。
4. 彩色光若落到脸上，也必须落到同方向的衣物、墙面、道具反射和阴影边缘；只有皮肤被青橙染色属于合成美化。
5. 皱纹、眼袋、鼻唇沟与发丝应由照明和焦点读出，不能靠 HDR、clarity、锐化或局部对比雕刻。
6. 皮肤、头发、毛织物、墙面、金属和釉面有不同粗糙度。全部出现同样油亮或脏亮等同于共享 CG shader，直接失败。

画面即使“很有气氛”，只要皮肤高光、彩光传播或局部对比无法由 `material_response_contract` 解释，就不能通过实拍门。

## AI 味检查

Codex 查看原图，不仅阅读提示。以下八项写入 `authenticity_qa.checks`：

| 检查 | PASS 的证据 | 常见硬失败 |
|---|---|---|
| `casting_specificity` | 个体年龄、体型、非对称和姿态属于角色 | 模特脸、同质化俊美、角色年龄漂移 |
| `human_surface` | 皮肤、毛发、眼睛、牙齿和衣料局部响应不同；皮肤高光符合光源大小/方向和干湿状态 | 塑料皮、均匀毛孔、无来源油膜、玻璃眼、漂白牙齿 |
| `set_causality` | 空间、设施、陈设和磨损存在因果 | 通用高级场景、随机 clutter、无法建造 |
| `lighting_causality` | 光源、方向、衰减、阴影和反射一致 | 浮动补光、无来源轮廓光、冲突阴影 |
| `composition_contingency` | 构图符合摄影者通路和叙事任务 | 无理由的英雄中心构图、每层都完美安排 |
| `material_contact` | 重量、接触、握持、衣物压力与材料响应成立 | 漂浮、穿插、无压力形变、镜面反射错误 |
| `artifact_absence` | 景深、文字、边缘和局部纹理无典型生成伪影 | 假散景、AI 字、HDR/clarity halo、统一彩边/颗粒、游戏过场式锐化 |
| `brief_fit` | 精致度、偶然性和后期符合本项目 | 观察式剧情被做成广告，广告却像随机抓拍 |

任一项 `fail`，`ai_smell_verdict` 必须为 `fail`。自动检查不能看懂像素；Codex 必须查看实际图片并记录可定位原因。

## 失败与升级

- 第一次失败只允许选一个首要可观察问题，建立新版本重新 `generate` 或在身份/地理必须保留时 `edit`。
- 第二次仍失败：人物或地点权威锚点设为 `rejected`，`escalation=real_reference_required`，停止依赖资产。
- 用户参考只能是其拥有或获许可的照片。涉及可识别真人时还需确认身份同意；不从公开案例、搜索结果或社交媒体抓图代替。
- 叙事图失败但现实锚点通过时，拒绝当前摄影策略；不能用调色或颗粒补救。重新设计 capture circumstance 或 Profile。
- 被拒绝、被替代、失败或等待真人参考的资产不得成为权威引用。
- 旧提示或已知会产生游戏过场/塑料皮的条件只保留为隔离失败证据，不再次生成，也不作为用户候选；盲选集合必须先逐张通过硬门。

## 模型校准表

内置 ImageGen 会变化，Higgsfield 的相机/镜头词又经过平台专属调校。仅把重复 A/B 测试中产生稳定、可观察收益的提示结构带入生产。校准记录至少包含：日期、ImageGen 后端、场景族、基线提示、单一变量、独立重复次数、两次结果、引入的失败、`retain | conditional | drop` 决定。

默认规则：

- 保留具体人物、地点、光源、摄影发生条件和参考图职责。
- 有条件使用焦段、工作距离、景深和快门等可观察行为。
- 默认删除品牌串、电影片名、导演名、`masterpiece`、`award-winning`、`8K` 和无行为定义的 `cinematic`。
- 颗粒、halation、色差、bloom、gate weave 和 LUT 只在基础真实已通过后考虑，且必须局部、介质相容、有预算。
