# v1.6 原创电影语法与画幅系统

“电影感”不是统一的浅景深、青橙、逆光、颗粒或黑边。它是剧本、摄影机为何在场、可用空间、真实光源、演员行为和时间采样共同形成的观看制度。本页把影视参考翻译成原创、可观察、可重建的摄影行为。

## Script-to-treatment 轴线

每个 `cinematic_treatment` 必须逐项回答：

- `narrative_distance`：观众与人物是贴近、观察、追随还是俯瞰。
- `observer_identity`：摄影机属于受控剧组、现场见证者、剧情内记录者、监控/档案设备或表演舞台。
- `composition_order`：构图是稳定、呼吸式、压迫、开放、几何精密还是受事件打断。
- `spatial_optical_behavior`：工作距离、前后景关系、透视、焦点和遮挡怎样讲故事。
- `motivated_light_strategy`：哪些真实光源组织曝光、肤色、反射和暗部。
- `color_pipeline`：色彩来自世界中的物体/光源以及怎样的显示转换，不是通用 LUT 名称。
- `support_and_inertia`：三脚架、肩扛、轨道、稳定器等为何出现，质量和落稳怎样可见。
- `temporal_rhythm`：镜头时长、动作节拍、拍摄/交付帧率与快门如何服务叙事。
- `environmental_medium`：空气、水、雨雪、烟尘怎样改变距离、光和材质。
- `polish_ceiling`：作品允许多受控、多偶然、多精致。
- `named_reference_policy`：导演、摄影师、片名和品牌不进入模型提示。
- `observable_reference_translation`：把用户参考译成上述行为，而非模仿署名风格。
- `return_rule`：序列覆盖何时回到全片基线。

## 原创起点，不是滤镜

以下族只帮助提问，最终 Treatment 可以混合，但必须自洽：

- `naturalistic_dialogue`：可住人的空间、可用光、克制移动、表演优先。
- `nocturnal_crime`：暗部有层级，混合实景灯有因果，运动带操作限制。
- `grounded_horror`：信息受限、空间压力和画外威胁，不用装饰雾和无来源逆光。
- `period_reconstruction`：资料边界、年代材料/照明/取景限制先于“复古滤镜”。
- `epic_environment`：地形、天气、尺度与人物关系主导，不把角色做成游戏海报。
- `kinetic_action`：路径、重量、碰撞、视差、呼吸和落稳主导，不以随机抖动代替速度。
- `intimate_romance`：观看距离、眼神、微动作和呼吸空间主导，不默认柔焦美容。
- `precision_commercial`：可控几何、材质分离和重复动作主导，但仍避免塑料 PBR 质感。
- `performance_mv`：表演节拍、舞台光源、镜头/剪辑节奏主导，精致必须有制作理由。
- `archive_surveillance`：设备位置、固定画幅、时间/曝光限制主导，不添加无设备依据的损伤。
- `custom`：仍需填满全部轴线。

题材不会自动绑定某一族；同一项目也不能为了“变化”而无理由切换语法。

## Format approval gate

Look Test 前先批准 `format_plan`：

- 捕获画幅、工作框线与交付画幅。
- 画面安全区、裁切和后续重构策略。
- 变形镜头 squeeze/desqueeze 与交付裁切。
- 序列覆盖的转换设计、叙事理由和回归规则。
- `baked_black_bars:false`。

默认 16:9。1.33/1.37、1.66、1.85、2.00、2.39、9:16 或序列级变化必须解释人物、空间或观看媒介如何受益，并由用户批准。画幅是构图约束，不是生成一张带黑边的图片。

## Look Test 的真实差异

同一比较组固定身份、状态、地点、时间、环境、剧情事件、人物空间关系与批准画幅。A/B/C 三套方案各自独立生成，不能互相编辑；在下列七类中至少三类有实质差异：

1. 摄影机为何在场与可达位置。
2. 机位、工作距离、焦段、透视和焦点。
3. 承托、路径、惯性和落稳。
4. 曝光优先级与合理光源组织。
5. 环境介质及其光学/材质影响。
6. 拍摄帧率、快门和动作采样。
7. 经批准的画幅/重构方案。

只换色温、LUT、颗粒、halation 或无来源轮廓光直接失败。每套 Look 先经过后台候选池与摄影、几何、统一 `live_action_quality_qa`，再把三套合格结果隐藏 Profile 后放进 Foundation 门盲选。旧版坏提示、故意脏化的负面对照和任何已知失败图只可隔离留档，不能重新生成或拿给用户从中挑选。

每套 Look 还必须明确皮肤受光行为：主光真实来源、相对尺寸/方向、干湿状态、预期高光范围、局部对比与彩光传播。三套可以改变这些摄影条件，但不能用“青橙双边光 + 油亮皮肤 + 英雄姿态”制造表面差异。人物动作应由剧情任务、重心与摄影机见证位置产生，而不是为了填满画面摆成预告片海报。

## Medium signature

`calibrated_medium_signature` 只能用于叙事资产，不得污染人物、地点或物件根。每个签名要记录适用题材、可观察目标、两次独立 A/B 证据、失败症状和状态：

- 只有两轮独立候选都通过 `live_action_quality_qa` 且达到发布阈值才能标记 `stable`。
- 不稳定、跨材质复制、皮肤结块、低频涂抹、锐化亮边时标记 `rejected`。
- 没有稳定签名时自动使用洁净数字成像；这不是创意失败，而是安全基线。
- 介质签名不是统一滤镜；每个场景仍服从光源、曝光、材料和叙事距离。

## 影视参考处理

用户可以提供影片、摄影师、年代或流派作沟通参考。内部先写“可观察翻译表”，例如观看距离、镜头高度、前后景占比、光源大小/方向、暗部底线、颜色来源、承托惯性、节拍与瑕疵预算。最终 ImageGen/视频提示不得包含导演、在世艺术家或片名来替代这些事实，也不得声称真实使用了指定机身、镜头、胶片或 EXIF。

## 硬失败

- 所有题材都收敛为浅景深、青橙、逆光和颗粒。
- 皮肤呈统一油膜、小亮斑与声明光源大小不符，或青橙肤色污染没有同步传播到环境和服装。
- HDR/clarity 局部对比把五官、皱纹、发丝和衣料刻成游戏角色；人物姿态像英雄海报而不是正在发生的行为。
- 观察式剧情被美化成棚拍广告，或精密广告被随机弄脏。
- 无来源轮廓光、统一灰雾、无亮源的变形眩光。
- 画幅变化没有审批、转换或回归规则。
- 黑边烧进图像。
- Profile 只写品牌，不写物理原因、可观察结果和叙事理由。
