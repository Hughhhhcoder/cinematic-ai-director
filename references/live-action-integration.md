# v1.6.5 锁定地点的人物—实景融合探针

身份板、地点根和摄影参数分别合格，并不等于人物进入场景后仍像真实摄影。内置 ImageGen 可能把白底人物重新解释为带油膜的数字角色，或把人物与环境分别锐化、布光和 tone-map；这类图即使解剖、空间和动态范围字段完整，也不能进入生产。

因此所有含人物的真人项目，在 Look Test、Photoboard、关键帧、特殊天气、多人画面和 Ready 镜头之前，必须先通过一个普通条件下的 `live_action_probe`。v1.6.5 起，探针不再重新生成整张场景；它必须把已批准空场景作为不可变编辑底片，只在人物、接触物及物理必需的接触阴影区域内插入人物。

## 探针目的

探针只回答一个问题：当前身份根与地点根能否在同一张图中形成可信的实拍事件？它不是风格测试，不是英雄镜头，也不承担最终构图职责。

固定条件：

- 第一引用、`derived_from` 与 ImageGen 编辑目标必须是同一张已批准地点根或中性地点状态图。
- 第二引用只能是已批准的统一 4×2 身份 Inspector；它只提供人物身份、身体与服装。
- 不引用旧叙事帧、失败候选、Look、状态编辑链或桥接帧。
- 只出现一个成年人、一个地点和一个简单可读任务；优先让人物接触独立随身工作物，避免为了测试人物而遮挡或重绘权威家具。
- 使用可达的眼平中景或中近景，使脸、身体、工作手、接触物与周围空间同时可读。
- 只使用普通的大面积窗光、阴天光或已有室内光；关闭特殊天气、烟雾、火光、霓虹、彩色边光、介质签名、胶片模拟和英雄式造型。
- 仍保留有限动态范围：明确保护对象，并允许小光源核心溢出或最深暗部失去信息。

## 模型提示预算

使用 `image2-live-action-locked-insertion-probe-v1.6`。提示保持 120–260 个英文词，仍采用六个可审计段落，但不把内部 QA、器材清单或完整摄影圣经发送给模型。

正向信息只包含：

1. `photorealistic candid on-location photograph` 与摄影事件。
2. 第一张是不可变地点底片、第二张是身份权威，以及两者互不替代的职责。
3. 不改变底片机位/裁切，可达机位说明、人物编辑框、任务、接触、遮挡和同一投影。
4. 一个普通光源如何同时到达人物与环境。
5. 焦点选择与有限曝光取舍。

排除项不超过 40 个英文词，只压缩为四组：合成/游戏人物；油蜡塑料皮肤；贴图边缘、人物独立 tone mapping 或重复伪影；机位、裁切、桌台尺寸/支撑、门窗、固定设施、主锚点和背景细节漂移。禁止在正向提示中使用 `cinematic`、片名/导演名、相机品牌、胶片、变形镜头、颗粒、光晕、特殊天气或宣传式灯光。

OpenAI 的官方图像提示指南建议结构化说明、明确引用图片的作用，并通过迭代修正而不是一次堆入过量细节；它同时说明图像输入应按顺序解释交互关系。这里采用这些可迁移原则，但不采用通用示例中的毛孔、磨损或颗粒词，因为本项目本地重复结果表明它们会放大脏纹和皮肤伪影：

- <https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide>
- <https://developers.openai.com/api/docs/guides/image-generation>

Higgsfield 的一致性流程支持人物与地点共同引用以及按序列携带强帧，但生成身份根仍不等于已经证明最终人物—场景融合；探针通过后才能采用该序列方法：

- <https://higgsfield.ai/blog/consistent-characters-locations>
- <https://higgsfield.ai/blog/realistic-ai-human-movement>

## 视觉硬门

Codex 必须在 thumbnail、fit、100% 和 200% 四个尺度检查并记录正向证据：

- 脸和皮肤在当前画面占比下可判断；皮肤为连续的自然干燥或明确状态响应。
- 工作手、接触物、支撑面、重力和遮挡连续。
- 同一光源方向、面积和室内反弹同时影响脸、衣物、接触物与邻近场景。
- 人物与环境共享焦点衰减、遮挡层级、边缘清晰度、空气状态和色彩污染。
- 亮部或暗部有真实损失，不存在人物单独 HDR、单独锐化或单独美容曝光。
- 皮肤、毛发、织物、墙面、木材、玻璃和金属保持不同响应。
- 空场景与人物入景图的桌台长/宽/厚度、前缘、支撑、门窗、固定设施、主锚点、消失关系、机位和裁切保持对应。

每个合格探针必须额外写入 `locked_scene_qa`：

- 至少六个归一化地标，覆盖家具、建筑和固定设施；每个地标的预期/观察位置、可见性和容差都要记录。
- 明确 `bounded_edit_regions`；区域外变化不能被人物遮挡解释时即失败。
- 将输出仅用于审计地缩放到编辑底片尺寸，记录编辑框外 MAE、P95 与大变化像素比例；默认上限分别为 `6/255`、`20/255` 和 `5%`。审计缩放不能替换或修改获批原图。
- 输出与底片画幅比偏差超过 0.5%、任何结构地标漂移、桌台细节改变或出现未声明的全局重调色，直接失败。

以下任一项直接失败：

- 油膜、蜡质、塑料皮肤或来源不明的密集小高光。
- 人物像游戏角色、CG/PBR 模型、插画或被贴入背景。
- 人物边缘比相邻场景统一更锐，或人物与背景有两套 tone mapping。
- 人物未受现场空气、光线、接触阴影或反射影响。
- 重复纹理从皮肤泄漏到衣物、墙面或物件。
- 比例、接触、重心、透视或遮挡错误。
- 所有亮暗区域都被 HDR 式局部提亮并同等清晰。
- 桌面深度/厚度、前缘、腿或支撑数量改变；门窗、柜体、纸张、固定灯具、锚点、背景地平线或消失点漂移。
- 以“参考图相似”冒充地点锁定，或在人物编辑框之外重新生成整间房。

## 批次与阻断

- 第一批是三个彼此独立的编辑候选；三次都直接编辑同一张批准空场景，候选不能互相编辑。
- 若至少一个通过，选唯一通过者并记录正向证据。
- 若第一批全败，只针对共同最高优先级失败原因修改一个变量，生成第二批独立候选。
- 第二批仍无通过者，记录 `backend_realism_blocked`，不再生成 Look、特殊环境、多人镜头、Photoboard、关键帧或 Higgsfield 包。
- 阻断后只能请求拥有使用权且获得真人同意的实拍人物/地点照片，或把项目降为不承诺真人像素的 package-only/previs 工作。禁止用后期清理、降采样、锐化或调色掩盖失败。

`pixel_reproducible:false` 仍然成立。Skill 能保证失败像素不进入生产，而不能保证随机模型第一次就输出合格像素。
