# 内置 ImageGen 校准：干净成像与一致性

这是模型特定、可变的实测层，不是普遍摄影理论。每次内置 ImageGen 行为明显变化，或一个题材连续触发同类失败时，都在隔离项目中重复测试；不能从 Higgsfield、开源模型或器材名称推断内置 ImageGen 一定服从。

## v1.6 当前发布状态

日期：2026-08-27。v1.6 已实现质量 Profile、后台候选池、Foundation/Sequence 审批、确定性提示编译、角色身材目标、联合序列锚点和离线 Higgsfield 导出，并通过完整结构回归。这个结论只证明工作流会隔离失败并阻断未获批准内容，不代表内置 ImageGen 在所有题材首次生成时已经稳定。

- 用户提供的优秀观察式人物照片被转译为 `clean-observational-live-action-v001`：来源型柔光、连续自然肤色、克制局部对比、材质各自响应、生活因果布景和任务式表演。原图不打包、不复制人物/住宅/日间构图，也不进入生产引用。
- v1.6 每个项目重新建立 `project_quality_profile`；校准照片只提供评判底线，不能把观察式日间质感强加给夜景犯罪、广告、MV、恶劣天气或其他题材。
- 每个持续人物只允许一次单张高分辨率 3×2 身份 Inspector 生成；整板失败即停止该人物，不得以候选池重试同一身份。Look、地点、联合序列锚点和英雄关键帧仍采用后台候选池；只有通过原生清晰度、几何、摄影与正向实拍质量门的结果才可进入用户审批。
- `role_physique_brief`、量化目标和 `physique_fit_qa` 已进入结构发布门；目标驱动体态会淘汰比例差、轮廓错误或服装吞没体态的候选。但各类身材的模型视觉稳定率仍须在实际候选池中逐项目验证。
- 十二类 Treatment/环境两轮候选、跨场景十二镜头以及不同身材分类的视觉通过率，在没有保存真实独立生图证据前全部保持 `conditional/blocked`。不得把脚本测试、Higgsfield 案例或旧版基准冒充 v1.6 像素发布门。
- `medium_signatures` 默认 `disabled`；未校准题材回退 `clean_digital_capture`。不得用颗粒、halation、色差、bloom、锐化或脏化掩盖失败。

复现等级仍为 `workflow_only`、`pixel_reproducible:false`。可复现的是提示编译、引用顺序、候选隔离、审批和导出，不是随机像素。

## v1.5 安全状态（历史）

v1.4 的实测结论仍可作为洁净基线，但不能自动批准 v1.5 的人体几何、特殊天气、特殊光源、画幅、运镜或动态模糊能力。v1.5 在完成正向提示重复、16 张摄影差异和 12 镜头跨场景视觉基准前：

- `medium_signatures` 保持 `disabled`，不得自动套用颗粒、halation、bloom、色差或 gate weave。
- 叙事资产默认 `clean_narrative`；根资产始终 `clean_authority`。
- v1.5 当时要求七张身份图分别生成；这条历史规则已被 v1.6 明确废止，任何新项目都不得继续执行。
- 新环境/高速/多人接触能力逐镜审批，不得从旧样本推断稳定。
- 脚本回归通过只代表流程阻断有效，不代表像素视觉发布门已经跨过。
- 旧版坏提示只使用已经存在的历史输出作负面对照；不再生成新的坏图，也不把负面对照放进用户盲选。

## v1.5 接触场景失败证据与规则升级

2026-08-26 的厨房拿壶诊断中，旧提示负面对照连续呈现同一组硬失败：皮肤被均匀油亮层覆盖；青橙双边光与窗/灯位置无法对应；皱纹、发丝和衣料被局部对比锐化成游戏角色；墙、服装与壶共享同一种亮脏粗糙度；人物伸手和凝视被安排成预告片海报。两张均被用户明确拒绝，不进入候选、校准保留项或下游参考。

由此新增并保留：

- 含人物资产必须填写可验证的 `material_response_contract`，明确皮肤光源大小/方向、干湿、高光范围、色调映射、材质粗糙度与表演策略。
- `live_action_surface_qa` 独立检查皮肤高光拓扑、肤色连续性、局部对比、粗糙度分离、游戏过场签名和宣传姿态。
- 默认阻断 `dramatic/cinematic rim light`、`hero lighting/pose/composition`、`premium cinematic`、`glossy/cinematic skin`、`HDR look/lighting`、`game cinematic`、`trailer still` 等合成快捷词。
- 视频模型提示同步携带皮肤主光、干湿、高光范围、局部对比与材质粗糙度，并明确排除游戏过场式表面。
- 已知坏提示与旧输出进入隔离证据；不重新生成、不参与盲选。视觉发布门继续保持关闭，直到正向条件在独立重复中通过。

## 跨场景一致性基准

同一虚构检查员在厨房、楼梯间、设备间三个地点，经历干燥基线、雨湿、湿衣加反光背心、干衣加左手绷带四个持续状态；同一厨房另测试日间、夜间、重新布置、受损和离开后返回。最终保留 8 张内部基准叙事帧。

通过项：

- 三个地点都直接引用各自干净地点根；厨房的固定拓扑、窗、门、工作台和主锚点在状态变化与返回帧中保持可识别。
- 四个角色状态均直接引用脸部、身体、七视图根，而非上一状态；湿润、背心和绷带只作用于声明材质/部位。
- 8 张保留帧在缩略图、适配窗口、100% 和 200% 未触发纹理硬失败；脸部、体型、发际线和服装结构没有足以批准为新身份的漂移。
- 序列桥接只补充上一组构图/动作信息；根身份和地点根始终保留在引用表。

阻断项：

- “右袖肘部约 2 cm 撕口”两次都被放大成更显眼的破损，状态标记 `model_blocked`，后续帧未引用。小于当前画面可验证尺度的损伤不能用近似结果冒充通过。
- 一个右手惯用角色的持板动作连续两次落到左手，标记 `model_blocked`，并改写为不持道具的独立剧情瞬间；不能靠继续堆词消耗尝试。
- 左手绷带的叙事帧第一次镜像到右手；第二次同时写“人物解剖左手”与该机位下的“观看者画面右侧”后纠正。由此只保留一条条件规则：关键左右侧状态必须同时绑定解剖侧、场地关系和由机位推导的画面投影，并逐图检查；该文字仍不是保证。

证据位置：

- 机器可读结果：`qa/cross-scene/results.json`
- 根、状态、8 帧与失败候选：`qa/cross-scene/`
- 人脸对照与四尺度接触表：`qa/cross-scene/contact-sheets/`
- 状态/序列审计：`qa/cross-scene-review.md`

## 已发布校准表

### `retain`

1. 权威资产使用 `clean_authority`；只写几何、结构、材料类别、颜色和中性拍摄事实。
2. 叙事资产从全部批准根直接生成；提示只加入当前状态增量、剧情瞬间、摄影发生条件与少量可见光线事实。
3. 固定四类排除：`no painterly smearing; no repeating swirl or scale pattern; no copied texture across unrelated materials; no oversharpened halos`。
4. 地点以少量高区分度拓扑、固定设施和主锚点关系锁定，不用随机脏乱代替使用历史。
5. v1.6.6 人物以一次生成并整板通过的高分辨率 3×2 Inspector 锁定；六张确定性裁图仅供检查/UI，当前状态不能取代 Inspector。旧版 4×2 作为已有项目适配器，face/body/turnaround/多次独立生成结论只保留为历史证据。
6. 关键左右手、伤势或道具绑定同时写解剖侧、场地固定关系和当前机位下的观看者投影。
7. v1.6.6 的三次单次身份板实测中，明确排除词仍未稳定消除地形线/迷宫式人脸底纹；因此只保留“原生 100%/200% 硬门与失败隔离”这一工作流结论，不把任何负面词宣称为已校准修复。

### `conditional`

1. 纯文本干净提示可建立根候选，但不能证明身份、地点或制造结构一致。
2. `localized_story_evidence` 只有在目标特征大到足以从资产分辨率明确验收时才使用；否则先生成专用近景权威或请求合法实拍参考。
3. 独立参考驱动生成提升一致性，但仍逐张执行身份、拓扑、结构、真实性和纹理 QA。
4. 桥接尾帧只能补充序列动作/构图，不能替代根权威。

### `drop`

1. 默认正向禁用 `weathered / worn / gritty / tactile texture / patina / fingerprints / pores / film grain / microtexture / ultra-detailed / 8K`。
2. 不以 `cinematic / masterpiece / award-winning / photorealistic` 代替可观察事实。
3. 不将一个状态递归编辑成下一状态，不引用失败候选，不靠后期清理器掩盖纹理失败。
4. 不用屏幕左/右作为人物身体侧或场地关系的唯一描述。
5. 不因有多张参考就宣称模型会逐像素复现；所有可见漂移仍由审批门淘汰。

## 重新校准触发

- 同一保留策略在两个连续项目中触发同类纹理或身份漂移。
- 内置 ImageGen 的生成/编辑行为明显变化。
- 新题材需要尚未验证的微距、透明/高反材料、水下、高速车载或群体接触。
- 需要启用任何默认禁词时，必须针对明确资产族做两次独立 A/B，并同时保存原图、200% 诊断、失败和决定。

历史 v1.2 文字消融、v1.3 空间实验与 v1.4 洁净/跨场景基准仍保存在各自 benchmark 中，用于回归和解释规则来源；它们不覆盖 v1.5 尚未执行的视觉发布门。
