# Support

- Usage and reproducible bugs: [GitHub Issues](https://github.com/Hughhhhcoder/cinematic-ai-director/issues)
- Workflow questions and production patterns: [GitHub Discussions](https://github.com/Hughhhhcoder/cinematic-ai-director/discussions)
- Security or private rights/consent issues: GitHub private security advisory

Before filing a bug, run:

```bash
python3 scripts/film_project.py validate <project-dir> --json
python3 scripts/install_skill.py verify
```

Attach the validator JSON after removing private absolute paths and sensitive reference details. Never attach API keys, cookies, login sessions, or non-consensual real-person media.
