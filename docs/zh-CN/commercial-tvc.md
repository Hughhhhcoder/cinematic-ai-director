# 自适应商业广告与 TVC 导演

商业项目不是在电影末尾加一个 Logo。使用 `--project-kind commercial-tvc` 启动 TVC，商业 MV 使用 `music-video`。Skill 会创建 `manifests/commercial.json`，在创意、节奏、声音和交付合同批准前阻断生产镜头。

## Brief 与创意路线

先记录商业目标、受众、投放位置、委托时长、单一主张、理由依据、必备元素、品牌代码和成功指标。至少提出两条在受众机制、视觉逻辑和产品/服装证明上真正不同的路线。每条路线都必须通过竞品替换测试；只换 LUT、镜头名、天气或颗粒不算新创意。

## 镜头功能与时装证明

每个镜头必须有一个不可替代的功能及移除测试。时装项目还要逐套记录已批准人物状态、服装参考、轮廓、合体关系、材质行为、揭示镜头、细节证明和转场逻辑。六套衣服配六次相同慢走不能自动构成六个创意，也不能证明服装工艺。

## 节奏、速度和动态模糊

节奏计划把 BPM、拍号、首个强拍和能量曲线绑定到镜头秒数、准确帧数、beat 区间、动作峰值、切点关系和镜头内节奏事件，并明确同步、半拍、反拍、对白主导或自由时序。

合格剪辑必须满足：`beat_end - beat_start = duration_s × BPM / 60`（误差不超过 0.05 beat）、`duration_frames = duration_s × delivery_fps`，且全部生产镜头时长之和严格等于委托时长。

速度是一套按创意使用的工具，而不是全片统一升格：

`playback_rate = delivery_fps / capture_fps`

实时、升格慢动作、欠格加速、变速和静止分别记录拍摄/交付帧率、快门、曝光时间、动作目的和模糊逻辑。快音乐叠在整片低能量慢动作上会直接失败，除非有明确的半拍/反拍设计，并且画面内部确实存在可读的节奏事件。

## 声音与交付

根据 brief 规划对白/VO、经过剪辑的音乐、场景空气、服装/产品 Foley、转场重音、可选声音标识和混音层级。只有 BGM 不是完整 TVC 声音方案。

每个交付物都要记录目的地、精确时长/帧数、画幅/裁切、像素、帧率、编码/色彩、安全区和音频采样率/声道。720p/32 kHz 可以是审片代理，不能默认为商业母版；没有明确平台覆盖说明时，常规底线是至少 1920×1080 与 48 kHz。

只有会影响画面的创意、动作、速度和声音事实才进入 Higgsfield 支持的提示词段落。商业逻辑、移除测试、QA 和交付事实保存在 `commercial-direction.json`，避免模型提示被内部管理信息淹没。
