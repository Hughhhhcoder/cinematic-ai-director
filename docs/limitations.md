# Limitations, privacy, and safety

## Stochastic pixels

Built-in ImageGen does not expose a stable seed or immutable public model snapshot. `pixel_reproducible` is therefore always `false`. The Skill reproduces workflow, facts, prompt compilation, reference order, hashes, state locks, approvals, review-board composition, validation, and exports.

## Visual consistency

Identity, precise composition, hand/object contact, small localized damage, transparent/high-reflective materials, underwater action, fast vehicles, and crowded physical contact can fail. Candidate pools and hard gates contain failures; they do not turn a stochastic model into a deterministic renderer.

## Real people and rights

Web-scraped people cannot become identity roots. A real-person reference must be provided by the user with use rights and identity consent recorded. Public examples use fictional adults. Keep sensitive real-person assets out of public repositories and release packages.

## Platform boundary

Higgsfield adapter snapshots can become outdated. The package is an offline production work order, not an API integration. Re-check current public controls before manual execution. Unsupported controls block rather than degrade silently.

## Quality claims

Published visual capabilities require retained independent generation evidence and threshold results. A code test proves workflow logic, not visual model quality. Conditional or blocked treatment/environment modules must remain labeled until real pixel evidence passes.
